# 天空城最後一夜（Grok Bot version）

**Last Night of Aetheria — Grok Bot version**

浮空幻想城埃特里亞的最後二十分鐘。你扮演一名女天空騎士，在約一平方公里、五層垂直堆疊的可玩空間裡奔跑、攀爬、搭升降臺、進入關鍵建築、騎乘飛獸嵐羽，並在午夜城體崩裂時沿你學過的路逃脫。

這是可在瀏覽器遊玩的垂直切片，不是空擠開放世界。城很密，時間不夠，救不了所有人。

## 需求

- Node.js 20+
- 現代瀏覽器（Chrome / Edge / Firefox / Safari）

```bash
npm install
npm run dev
```

線上遊玩（GitHub Pages）：https://windfaller.github.io/last-night-of-aetheria-grok-bot/

開發伺服器預設：`http://127.0.0.1:4731`

建置：

```bash
npm run build
npm run preview
```

## 怎麼玩

1. 點「開始最後一夜」，再點畫面鎖定滑鼠。
2. 從市集區醒來。倒數約 20 分鐘（遊戲時辰 23:40 → 午夜）。
3. 五條委託同時進行。每條都會佔走你去救其他人的時間。
4. 午夜時城會在場景裡斷裂：建築傾斜、橋塌、飛艇逃散、碎塊墜入雲海。
5. 逃脫方式：崩落後跳上市集東側的天空渡輪，或騎嵐羽飛到觀星臺上方的高空。

### 同時進行的委託

| 委託 | 地點 | 不可逆的取捨 |
| --- | --- | --- |
| 齒輪裡的餘熼 | 工業底層鑄造廠 | 救萊拉並護送到渡輪，崩落時西側升降臺較穩 |
| 夜市離散 | 市集 | 三戶：立刻疎散（快）或幫他們打包貨物（慢，-25 秒） |
| 名字台地 | 住居台地禮拜堂 | 先找兩個走失孩子再敲鐘，或現在就敲、留下孩子 |
| 公爵的交易 | 貴族庭園 | 星錨遺物（庭園晚塌）**或**救三名僕役，不能兩全 |
| 星錨協議 | 王室觀星台 | 每啟動一座星錨，午夜延後 90 秒（第三座藏在底層） |

夜攤約在遊戲開始 10 分鐘後出現。工人在底層與市集之間移動，衛士沿外環巡邏，飛艇按時刻停靠。

## 五層城區

由下而上：

1. **工業底層** — 銅鏽、齒輪、管線，心輪鑄造廠
2. **市集區** — 夜市、茶寮、渡輪碼頭（預設出生點）
3. **住居台地** — 黏土屋頂、樹、末鐘禮拜堂
4. **貴族庭園** — 樹籬、噴泉、奧德里奇莊園
5. **王室觀星台** — 穹頂、望遠鏡、星錨控制臺

垂直移動：中央與四個方位的升降臺、連接各層的階梯橋、攀爬藤蔓／管線、嵐羽自由飛行並在有地面處降落。選定建築可走進室內（鑄造廠、茶寮、禮拜堂、莊園、觀星控制室），沒有讀取畫面。

## 技術

- **引擎**：Three.js + WebGL（Vite + TypeScript）
- **刻意選擇 WebGL 而非 WebGPU**：品質門檻要求中階筆電瀏覽器穩定幀率。WebGPU 在部分筆電上仍不穩；本版用 WebGL、像素比上限 1.5、大量 InstancedMesh、霧與著色器天空／雲海。
- **建築**：種子程序生成的密集街廓 + 手擺地標，不匯入大量模型。
- **NPC**：輕量路徑與時刻表，不是完整 AI。
- **崩落**：可玩空間內的剛體傾斜、碰撞橋樑失效、飛艇逃散、即時碎塊——不是純過場。

世界足跡直徑約 440m，五層可走表面合計接近 1 km²。

## 刻意刪減（垂直切片）

- 無帳號、無存檔、無多人。
- 無完整配音與編曲（程序音效：風、提示音、崩落低鳴）。
- 角色與坐騎為低面數幾何，非掃描模型。
- 多數房屋不可進入；只有五座任務建築有室內。
- 無完整布娃娃或破壞物理引擎；崩落是編導式剛體 + 碰撞剝除。
- 無遊戲內地圖，改用右側垂直城區尺。
- 對話進行時倒數仍走——這是設計，不是缺漏。
